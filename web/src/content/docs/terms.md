> **The short version.** Jobly is free and open source. It shows public job listings from other companies, so check details on the employer's site before you rely on them. Use the extension and the server fairly, and we'll keep them running as well as we can.

## Agreeing to these terms

By installing the Jobly extension or using this website or Jobly's server, you agree to these terms. If you don't agree, please don't use them. The [privacy policy](/privacy) explains how data is handled and is part of these terms.

## What Jobly does

Jobly collects public job postings from company career pages and job boards and shows them to you with their posting date. When you apply, you leave Jobly and apply on the employer's own site. Jobly is not an employer, recruiter or agency, and it does not take part in any hiring decision.

## Job listings belong to others

- Listings, company names and logos belong to the employers and job boards that published them. Jobly is not affiliated with them, and showing a listing is not an endorsement.
- Listings can be wrong, out of date or already filled. Jobly hides anything older than 60 days and removes jobs the employer no longer lists, but it can't promise that every listing is current. Always check the employer's own page.
- If a listing looks like a scam or is clearly wrong, use **Report this listing** in the extension or [write to us](/support).

## Fair use of the server

Jobly's server exists to answer the extension and this website. Please don't:

- Send automated traffic at a rate that slows it down for others, or try to get around its rate limits.
- Try to break into it, test its security without telling us, or use it to attack anyone else.
- Resell its data or present it as your own service.

We may block traffic that does this. If you want to build on Jobly, the code is open source: run your own copy.
