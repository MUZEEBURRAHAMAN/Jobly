# Jobly website

Static site (landing page + privacy policy). No build step, no third-party requests, free on Vercel or Netlify.

## Before you publish
Edit `config.js`:
- `storeUrl`: your Chrome Web Store listing URL (leave empty until published; buttons then say "Coming soon").
- `contactEmail`: a public support address shown on the privacy page (leave empty to hide).

## Deploy (free)
**Netlify (no account linking needed):** app.netlify.com → *Add new site → Deploy manually* → drag this `site` folder in.
**Vercel:** vercel.com → *Add New Project* → import the repo → set **Root Directory** to `site` → Deploy.
Use the resulting `https://…/privacy` address as the **Privacy policy URL** in the Chrome Web Store dashboard.

Screenshots in `assets/` are generated by `npm run e2e:screens` (from `extension/`), using fictional demo companies.
